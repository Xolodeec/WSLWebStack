# WSLWebStack

## Назначение

Проект автоматизирует разворачивание локальной серверной среды внутри WSL2 на Windows для разработки и тестирования PHP-проектов. Стартовая панель открывается на `https://localhost/`.

## Что делает установщик

Скрипт устанавливает и настраивает:

- импорт рабочего WSL-дистрибутива из **уже установленного** Ubuntu (шаг 1; `install.bat` дистрибутив Ubuntu не скачивает)
- Apache + PHP
- MySQL
- RabbitMQ
- phpMyAdmin
- Composer
- веб-панель `https://localhost/` для управления локальными доменами
- Cloudflare Quick Tunnel (если доступна установка `cloudflared`)

## Единственный файл запуска

Для установки и повторного запуска используется только:

- `install.bat`

Запускать строго от имени администратора.

## Системные требования

- Windows 10/11 с поддержкой WSL2
- права администратора
- 10–15 GB свободного места
- доступ в интернет во время установки

## Установка

1. Установите дистрибутив **Ubuntu 24.04** для WSL (`Ubuntu-24.04`): например `wsl --install -d Ubuntu-24.04` или приложение **Ubuntu 24.04** из Microsoft Store. При запросе перезагрузите ПК; убедитесь, что в `wsl -l -v` есть **Ubuntu-24.04** (или другой подходящий Ubuntu из Store — установщик использует его как источник копии).
2. Склонировать репозиторий или распаковать архив.
3. Запустить `install.bat` от имени администратора.
4. Если Windows попросит перезагрузку, перезагрузить ПК.
5. Снова запустить `install.bat`.
6. Открыть `https://localhost/`.

Повторный запуск `install.bat` допустим и используется как штатный способ донастройки.

**Имя WSL-дистрибутива:** по умолчанию `WSLWebStack` (виден в `wsl -l -v`). Изменить имя можно в `windows/WSLWebStackConfig.ps1` (`$script:WslDistroName`). Если Windows сначала ставит Ubuntu из Microsoft Store, это нормально: он нужен как источник копии на первом шаге. После второго запуска `install.bat` появится отдельная запись вашего имени из конфига, она будет дистрибутивом по умолчанию. Дистрибутив Ubuntu при желании можно удалить (`wsl --unregister`), если он больше не нужен.

## Результат установки

После завершения будут доступны:

- `https://localhost/` — панель управления доменами
- `https://localhost/phpmyadmin` — phpMyAdmin
- `http://127.0.0.1:15672/` — RabbitMQ Management

## Учётные данные и логи

Установщик сохраняет служебные данные в каталоге проекта:

- `credentials/` — пароли сервисов
- `logs/` — логи установки Windows и Linux-провижининга

Пароли не выводятся в консоль и читаются из файлов в `credentials/`.

## Структура проекта

- `install.bat` — единая точка входа
- `windows/` — подготовка WSL и интеграция с Windows
- `linux/` — модули провижининга внутри WSL

## Если сайт не открывается

- Запустить `install.bat` повторно от администратора.
- Проверить последние файлы в `logs/`.
- Проверить список WSL-дистрибутивов (`wsl -l -v`) и при необходимости запустить нужный.
